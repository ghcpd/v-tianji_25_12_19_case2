# Movie Ticket App

A frontend-only movie ticket booking UI built with React + Vite + TypeScript. Uses in-memory mock data and Vitest for unit tests.

## Scripts

- npm install
- npm run dev (start dev server)
- npm run test (run vitest)
- npm run test:coverage (run tests with coverage)
- npm run build
- npm run preview

## Notes

This project is a demo app for browsing movies, selecting showtimes and seats, and recording bookings in memory. All data is mock/in-memory and no backend is required.
